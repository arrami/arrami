# Contribuer

Ce dépôt est personnel mais ouvert aux retours.

## Signaler un problème
Ouvrez une issue avec le label `bug` ou `enhancement`.

## Proposer une amélioration
Fork + Pull Request, ou simple suggestion dans les issues.

## Standards
- Conventional Commits pour les messages
- Diagrammes Mermaid pour les architectures
- Accessibilité RGAA/WCAG dans chaque fiche
