# 🗺️ Roadmap du Projet

Ce document trace l'évolution future du référentiel **Architectures Web & IA**. Il est mis à jour régulièrement pour refléter les nouvelles priorités, les retours d'expérience et l'alignement avec les standards de qualité (RGAA, éco-conception, interopérabilité).

## 🎯 Court terme (Pratique, Scripts & Interopérabilité)
- [ ] **Scripts SEO & NLP pratiques** : Extraction de données, analyse de SERP, génération automatisée de Schema.org, et scripts SpaCy pour l'extraction d'entités.
- [ ] **Workflows n8n** : Automatisation de flux concrets (ingestion documentaire, veille, publication multi-plateformes).
- [ ] **Pipeline d'ingestion patrimoniale vers IA** : Architecture et script pour transformer des données structurées (Omeka S / Zotero / Dublin Core) en base de connaissances pour un modèle RAG. *(Livrable différenciant : lien entre culture, patrimoine et IA).*
- [ ] **Configuration Hetzner** : Guide pas-à-pas de déploiement d'instances, sécurité, backup et monitoring pour des architectures souveraines.

## 🚀 Moyen terme (Industrialisation, Qualité & Architecture)
- [ ] **Volet Accessibilité & Éco-conception** : Création d'une "Checklist RGAA/WCAG pour architectures Headless & IA" et intégration de tests automatisés (Axe-core / Playwright) dans les templates de démarrage.
- [ ] **Bibliothèque de snippets réutilisables** : Hooks WordPress, requêtes SQL optimisées, scripts bash et configurations Mermaid modulaires.
- [ ] **Templates de projets "Production-Ready"** : Starters Astro, Next.js et WordPress FSE avec les bonnes pratiques (SEO, A11y, perf) déjà intégrées.
- [ ] **Site statique Astro** pour publier les fiches (navigation améliorée, recherche full-text, tags dynamiques, SEO optimisé).

## 🌍 Long terme (Ouverture, Communauté & Retours d'expérience)
- [ ] **Études de cas réelles** : Documentation technique approfondie des projets Tasdawit, Madacity, Kabyle.com et LyonInfo.fr comme références d'architectures durables et éthiques.
- [ ] **Export PDF automatique** des fiches (via GitHub Actions pour un partage hors-ligne et une utilisation en jury/formation).
- [ ] **Version anglaise** des fiches clés (pour une audience internationale et une contribution open source élargie).

---

## 📈 Alignement avec les Tendances du Marché

Ce référentiel se concentre délibérément sur les compétences à forte valeur ajoutée identifiées comme prioritaires dans l'industrie tech actuelle :

- ✅ **Architecture informatique & Conception de systèmes** : Fiches d'architecture complètes avec schémas Mermaid et choix de stack justifiés.
- ✅ **Résolution de problèmes complexes** : Cas pratiques concrets avec des solutions éprouvées (RAG, Headless, NoCode).
- ✅ **Maîtrise stratégique du numérique** : Interopérabilité des données, souveraineté (Hetzner), et éthique (RGAA, éco-conception).

> **Positionnement** : Ce dépôt ne forme pas au code pur (devenu une commodité), mais à la **conception d'écosystèmes numériques robustes, accessibles et pérennes** — les compétences qui créent de la valeur durable.
